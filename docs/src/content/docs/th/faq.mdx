## ใช้กับ framework ไหนได้บ้าง?

ได้ทั้งหมด แกนหลักเป็น TypeScript ธรรมดาที่ไม่มีโค้ดของ framework จึงใช้ได้กับ JavaScript ธรรมดา, React, Next.js, Vue, Svelte และอื่นๆ ที่รันบนเบราว์เซอร์ ส่วน React มี entry เสริมเล็กๆ คือ `sharkzen-toast/react`

## ขนาดเท่าไหร่?

ไม่ถึง 7 kB (gzip) ทั้งไลบรารี รวมสไตล์และ icon โดยไม่มี dependency entry ของ React เพิ่มอีกไม่กี่ร้อยไบต์

## ต้องวาง container หรือ import CSS ไหม?

ไม่ต้อง toast แรกจะสร้าง container และฝังสไตล์ให้เอง

## ใช้กับการเรนเดอร์ฝั่งเซิร์ฟเวอร์ได้ไหม?

ได้ ไม่มีอะไรแตะ `document` หรือ `window` ตอน import และการเรียกฝั่งเซิร์ฟเวอร์จะไม่ทำอะไร

## เปลี่ยนหน้าตาได้ไหม?

ได้ ใช้[ตัวแปร CSS](../guides/theming/)ปรับสีและความโค้งของมุม หรือเลือกหนึ่งในสามธีม

## รองรับการเข้าถึงไหม?

toast ผิดพลาดประกาศแบบเร่งด่วน ที่เหลือประกาศแบบสุภาพ hover หรือโฟกัสแล้ว toast จะหยุดนับเวลา ปุ่มปิดกดด้วยคีย์บอร์ดได้และมี label และแอนิเมชันสั้นลงสำหรับผู้ที่เลือกลดการเคลื่อนไหว

## ใช้กับ Content Security Policy แบบเข้มงวดได้ไหม?

สไตล์ถูกเพิ่มผ่าน element `<style>` ตอนรัน ถ้าเว็บของคุณบล็อก inline style ด้วย `style-src` แบบเข้มงวด element นี้จะถูกบล็อก หากกระทบคุณ รบกวนเปิด issue เพื่อให้เราเพิ่มการรองรับ nonce

## เรียก toast จากนอก component ได้ไหม?

ได้ แค่ import `toast` แล้วเรียก เป็นฟังก์ชันธรรมดา ใช้ใน API client, event handler, store หรือที่ไหนก็ได้
