## ธีม

มีธีมในตัว 3 แบบ ตั้งแบบรวมหรือเฉพาะ toast ก็ได้:

```ts
toast.configure({ theme: 'light' }) // ทุก toast
toast.success('บันทึกแล้ว', { theme: 'colored' }) // เฉพาะอันนี้
```

| ธีม | หน้าตา |
|---|---|
| `dark` (ค่าเริ่มต้น) | การ์ดสีเข้ม icon และหลอดเวลามีสีตามประเภท |
| `light` | การ์ดสีขาว สีเน้นเข้มขึ้นเพื่อให้อ่านชัด |
| `colored` | พื้นหลังสีทึบที่เปลี่ยนตามประเภทของ toast |

## ใช้สีของแบรนด์คุณ

กำหนดสีของแต่ละประเภท toast เองได้ ประเภทที่ไม่ตั้งจะใช้สีที่มากับไลบรารี:

```ts
toast.configure({
  colors: {
    success: '#14b8a6',
    error: '#f43f5e',
    info: '#8b5cf6',
    warning: '#facc15',
  },
})
```

ใช้สี CSS แบบไหนก็ได้ สีนี้จะลงที่ icon และหลอดเวลาในธีม `light` กับ `dark` และกลายเป็นสีพื้นหลังในธีม `colored` ในธีม `colored` ถ้าเป็นสีอ่อนแบบ `#rgb` หรือ `#rrggbb` เช่นสีเหลืองข้างบน ตัวอักษรจะเปลี่ยนเป็นสีเข้มให้อัตโนมัติเพื่อให้อ่านออก ส่วนรูปแบบอื่นเช่น `rgb()` หรือชื่อสี จะใช้สีตัวอักษรของธีมตามเดิม

ตั้ง `colors` เฉพาะ toast ตัวเดียวก็ได้:

```ts
toast.warning('พื้นที่ดิสก์เหลือน้อย', { colors: { warning: '#f97316' } })
```

หรือไม่ต้องใช้ JavaScript เลย ใช้ตัวแปร CSS ได้: `--sz-success`, `--sz-error`, `--sz-info`, `--sz-warning`, `--sz-loading` และ `--sz-default`

```css
:root {
  --sz-success: #14b8a6;
  --sz-error: #f43f5e;
}
```

อยากใช้สีเดิมของไลบรารี แค่ไม่ต้องตั้งอะไร ทุกอย่างทำงานได้โดยไม่ต้องมีสีเหล่านี้


ประกาศทับตัวแปรเหล่านี้ที่ไหนใน CSS ของคุณก็ได้ เช่นที่ `:root`:

```css
:root {
  --sz-bg: #0b1220;
  --sz-fg: #e2e8f0;
  --sz-border: #1e293b;
  --sz-muted: #94a3b8;
  --sz-radius: 8px;
  --sz-font: "Inter", sans-serif;
}
```

| ตัวแปร | ควบคุม |
|---|---|
| `--sz-bg` | สีพื้นหลัง |
| `--sz-fg` | สีข้อความหัวเรื่อง |
| `--sz-border` | สีเส้นขอบ |
| `--sz-muted` | สีข้อความคำอธิบาย |
| `--sz-accent` | สีของ icon หลอดเวลา และปุ่ม action |
| `--sz-radius` | ความโค้งของมุม |
| `--sz-font` | ฟอนต์ ถ้าไม่ตั้ง toast จะใช้ฟอนต์เดียวกับหน้าเว็บของคุณ |

## ตำแหน่ง

`top-left`, `top-center`, `top-right`, `bottom-left`, `bottom-center` และ `bottom-right` แต่ละตำแหน่งจะเลื่อนเข้ามาจากทิศที่เหมาะกัน

โดยปกติ toast ใหม่จะอยู่ใต้อันเก่า ตั้ง `newestOnTop: true` ใน `toast.configure()` เพื่อกลับด้าน ซึ่งเข้ากับตำแหน่งด้านล่างได้ดี

## แอนิเมชัน

`bounce` (ค่าเริ่มต้น), `slide`, `zoom` และ `flip` ถ้าผู้เข้าชมเปิดโหมดลดการเคลื่อนไหวในระบบ แอนิเมชันจะถูกย่นให้สั้นลงอัตโนมัติ

## การทำงานแบบ responsive

ไม่ต้องตั้งค่าอะไรเพิ่มสำหรับจอเล็ก เมื่อจอกว้าง 480px หรือน้อยกว่า toast จะเต็มความกว้าง เกาะขอบบนหรือล่างตามตำแหน่งที่เลือก และเว้นพื้นที่ปลอดภัยของอุปกรณ์ (รอยบาก และแถบด้านล่าง)

## ขวาไปซ้าย

`toast.configure({ rtl: true })` กลับเลย์เอาต์สำหรับภาษาอาหรับ ฮีบรู และภาษาอื่นที่เขียนจากขวาไปซ้าย
