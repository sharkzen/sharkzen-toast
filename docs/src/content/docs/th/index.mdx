## สิ่งที่ได้

<ul class="zfeatures not-content">
  <li><strong>ไม่มี dependency</strong><p>สไตล์และ icon อยู่ในแพ็กเกจแล้ว ขนาดไม่ถึง 7 kB (gzip) ไม่ต้องติดตั้งอะไรเพิ่ม</p></li>
  <li><strong>ใช้ได้ทุก framework</strong><p>แกนหลักเป็น TypeScript ธรรมดา ใช้กับ JavaScript, React, Next.js, Vue และ Svelte import บนเซิร์ฟเวอร์ได้อย่างปลอดภัย</p></li>
  <li><strong>Promise toast</strong><p>แสดง toast กำลังโหลด แล้วเปลี่ยนเป็นสำเร็จหรือผิดพลาดได้จากการเรียกครั้งเดียว</p></li>
  <li><strong>Hover, โฟกัส, ปัด</strong><p>ตัวนับเวลาหยุดเมื่อ hover หรือโฟกัส และปัดไปด้านข้างเพื่อปิดได้</p></li>
  <li><strong>Light, dark และ colored</strong><p>ธีม 3 แบบ แอนิเมชัน 4 แบบ และ 6 ตำแหน่ง เปลี่ยนด้วย option เดียว</p></li>
  <li><strong>รองรับจอเล็ก</strong><p>บนมือถือ toast เต็มความกว้างและเว้นพื้นที่รอยบากกับแถบด้านล่างให้</p></li>
</ul>

## เรียกครั้งเดียวก็พอ

```ts
import { toast } from 'sharkzen-toast'

toast.success('บันทึกแล้ว', { description: 'การเปลี่ยนแปลงของคุณเผยแพร่แล้ว' })
```

ไม่ต้องมี provider ไม่ต้องวาง container และไม่ต้องใช้ไฟล์ CSS การเรียกครั้งแรกจะสร้างทุกอย่างที่ต้องใช้เอง
