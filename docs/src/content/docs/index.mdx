## What you get

<ul class="zfeatures not-content">
  <li><strong>No dependencies</strong><p>Styles and icons ship inside the package. Under 7 kB gzipped, nothing else to install.</p></li>
  <li><strong>Any framework</strong><p>A plain TypeScript core for vanilla JS, React, Next.js, Vue and Svelte. Safe to import on the server.</p></li>
  <li><strong>Promise toasts</strong><p>Show a loading toast, then turn it into success or error from a single call.</p></li>
  <li><strong>Hover, focus, swipe</strong><p>The countdown pauses while a toast is hovered or focused. Swipe sideways to dismiss.</p></li>
  <li><strong>Light, dark and colored</strong><p>Three themes, four transitions and six positions, all changed with one option.</p></li>
  <li><strong>Built for small screens</strong><p>On phones toasts go full width and respect the notch and home indicator.</p></li>
</ul>

## One call is enough

```ts
import { toast } from 'sharkzen-toast'

toast.success('Saved', { description: 'Your changes are live.' })
```

No provider, no container and no CSS file. The first call creates everything it needs.
